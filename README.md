# I SAW — 底片感相片藝廊

把自己拍的照片和影片，放進一個有紙質、蕾絲、載體的展示頁，
套上仿膠片的濾鏡，然後匯出成影片。

主檔是 **`film_gallery.html`**，單一檔案就是整個程式（純前端、零安裝）。

建立於 2026-09-14（從 `Lily_Mind/品牌專案/Photo` 搬過來自立門戶）。

## 怎麼跑

**雙擊 `serve.command`**，會自動開瀏覽器到 `http://localhost:8765/film_gallery.html`。

一定要走這個伺服器，不要直接雙擊 HTML。`serve.command` 處理掉三件事：

- 關掉佔用 8765 的舊程序
- 加上 `Cache-Control: no-store`（不然你會一直載到舊版）
- 支援 HTTP Range（不然影片沒辦法拖進度）

它也是多執行緒的，不然大檔案傳輸中其他請求會全部卡死。

## 幾個重點

- **看起來對不代表輸出對。** 畫面預覽和影片輸出是**兩套不同的渲染器**。
  輸出走的 canvas 不支援 `mask-image`、`backdrop-filter`、`background-blend-mode`。
  加新效果一定要先確認輸出路徑畫得出來。

- **輸出幀率鎖在 18fps 左右。** 原本只有 6.8fps 而且一頓一頓，修過三輪
  （SVG 遮罩光柵化快取、`captureStream(0)` + `requestFrame()`、暖機後鎖定幀率）
  才到 17.9fps。18fps 剛好是 Super 8 的原生幀率，跟這個專案的調性也合。
  想更快只能降解析度，或關掉遮罩與顆粒。

- **圖檔都是 WebP q94。** WebP 就算開有損，**alpha 通道是無損的**（實測誤差 0），
  所以描圖紙 3 和取景器的透明度沒被動到。原圖都留在 `source/`。

- **濾鏡是量出來的，不是調出來的。** 八個濾鏡裡七個有參考影片對照，
  參考片在 `source/方寸之間.mov`（其餘在 Lily 桌面）。只有〈黑白老電影〉沒有參考，
  是照默片的物理原則做的。

- **量測本身也會出錯。** CHANGELOG 記了至少三次假警報。下結論之前先確認量測方法是對的。
